# ByteVerse - Gamified Web Learning & Academy

> Created & Engineered by Affan Sayed
> Live Portfolio: https://affansayed.vercel.app/

ByteVerse is a next-generation interactive learning platform teaching HTML, CSS, JavaScript, PHP, MySQL, Python, and Django.

## Key Features
- W3-Style Academy with Try it Yourself execution
- ELI5 Storytelling with Audio Voice Narration for kids and beginners
- 7 Cyber Arcade Mini-Games
- 2-Player Split-Screen Code Duel Co-Op
- Full Responsive Design on Mobile, Tablet, and Desktop
